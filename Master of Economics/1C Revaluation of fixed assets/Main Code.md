## 💻 Код внешней обработки для переоценки ОС

Создайте внешнюю обработку в Конфигураторе 1С. В свойствах обработки укажите Имя `ПереоценкаОС`, Синоним `Переоценка ОС`. Добавьте основные реквизиты и команды.

Вот основной код модуля обработки с подробными комментариями.

### Модуль обработки

```bsl
// В начале модуля обработки объявляем ее реквизиты
// Они будут отображаться в форме для ввода данных пользователем

Перем ТекущаяДата;

// Процедура при создании обработки на сервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    
    // Устанавливаем дату проведения переоценки по умолчанию - текущая дата
    ТекущаяДата = ТекущаяДата();
КонецПроцедуры

// Основная процедура проведения переоценки
// Вызывается при нажатии кнопки "Провести переоценку" из формы
Процедура ПровестиПереоценку(Команда)
    
    // Проверяем заполнение всех необходимых полей
    Если Не ПроверитьЗаполнение() Тогда
        Возврат;
    КонецЕсли;
    
    // Выполняем основные операции на сервере
    ПровестиПереоценкуНаСервере();
    
    // Сообщаем пользователю об успехе
    Сообщить("Переоценка основного средства успешно проведена!");
КонецПроцедуры

&НаСервере
Функция ПроверитьЗаполнение()
    
    // Эта функция проверяет, заполнил ли пользователь все обязательные поля
    Если ОбъектПереоценки = Неопределено Тогда
        Сообщить("Ошибка: Не выбрано основное средство!", СтатусСообщения.Важное);
        Возврат Ложь;
    КонецЕсли;
    
    Если НоваяСтоимость <= 0 Тогда
        Сообщить("Ошибка: Новая стоимость должна быть больше нуля!", СтатусСообщения.Важное);
        Возврат Ложь;
    КонецЕсли;
    
    Возврат Истина;
КонецФункции

&НаСервере
Процедура ПровестиПереоценкуНаСервере()
    
    // Находим текущие параметры основного средства на дату переоценки
    ДанныеОС = ПолучитьДанныеПоОСНаДату(ОбъектПереоценки, ДатаПереоценки);
    
    // Рассчитываем коэффициент переоценки и новые значения
    РасчетныеДанные = РассчитатьПараметрыПереоценки(ДанныеОС, НоваяСтоимость);
    
    // Создаем и проводим документ "Бухгалтерская справка"
    СоздатьБухгалтерскуюСправку(РасчетныеДанные);
    
    // Корректируем параметры для будущей амортизации
    СоздатьИзменениеПараметровАмортизации(РасчетныеДанные);
    
КонецПроцедуры

&НаСервере
Функция ПолучитьДанныеПоОСНаДату(ОбъектОС, ДатаАктуальности)
    
    // Этот запрос получает актуальные данные по основному средству на заданную дату
    Запрос = Новый Запрос;
    Запрос.Текст = 
    "ВЫБРАТЬ
    |   ОсновныеСредства.Ссылка КАК Объект,
    |   ОсновныеСредства.ПервоначальнаяСтоимость КАК ПервоначСтоимость,
    |   ОсновныеСредства.СуммаАмортизацииБухгалтерскийУчет КАК АмортизацияБУ,
    |   ОсновныеСредства.СуммаАмортизацииНалоговыйУчет КАК АмортизацияНУ

    |   Документ.ПринятиеКУчетуОС КАК ОсновныеСредства

    |   ОГРАНИЧЕНИЕ 1"; // Берем самую последнюю запись на указанную дату
    
    Запрос.УстановитьПараметр("ОбъектОС", ОбъектОС);
    Запрос.УстановитьПараметр("ДатаАктуальности", ДатаАктуальности);
    
    Результат = Запрос.Выполнить();
    Выборка = Результат.Выбрать();

    КонецЕсли;
    
КонецФункции

&НаСервере
Функция РассчитатьПараметрыПереоценки(ДанныеОС, НоваяСтоимость)
    
    // Рассчитываем остаточную стоимость ДО переоценки
    ОстаточнаяСтоимостьДо = ДанныеОС.ПервоначСтоимость - ДанныеОС.АмортизацияБУ;
    
    // Рассчитываем коэффициент пересчета
    // Ключевая формула: коэффициент = Новая стоимость / Первоначальная стоимость
    КоэффициентПересчета = НоваяСтоимость / ДанныеОС.ПервоначСтоимость;
    
    // Рассчитываем новую сумму амортизации после переоценки
    НоваяАмортизацияБУ = ДанныеОС.АмортизацияБУ * КоэффициентПересчета;
    
    // Рассчитываем сумму дооценки/уценки стоимости
    СуммаИзмененияСтоимости = НоваяСтоимость - ДанныеОС.ПервоначСтоимость;
    
    // Рассчитываем сумму корректировки амортизации
    СуммаИзмененияАмортизации = НоваяАмортизацияБУ - ДанныеОС.АмортизацияБУ;
    
    // Возвращаем структуру с рассчитанными данными
    Результат = Новый Структура;
    Результат.Вставить("Коэффициент", КоэффициентПересчета);
    Результат.Вставить("СуммаИзмененияСтоимости", СуммаИзмененияСтоимости);
    Результат.Вставить("СуммаИзмененияАмортизации", СуммаИзмененияАмортизации);
    Результат.Вставить("НоваяСтоимость", НоваяСтоимость);
    Результат.Вставить("НоваяАмортизацияБУ", НоваяАмортизацияБУ);
    Результат.Вставить("ОбъектОС", ДанныеОС.Объект);
    
    Возврат Результат;
    
КонецФункции

&НаСервере
Процедура СоздатьБухгалтерскуюСправку(Данные)
    
    // Создаем новый документ "Бухгалтерская справка"
    БухСправка = Документы.БухгалтерскаяСправка.СоздатьДокумент();
    БухСправка.Дата = ДатаПереоценки;
    БухСправка.Содержание = "Переоценка основного средства: " + ОбъектПереоценки.Наименование;
    
    // Очищаем табличную часть и добавляем проводки
    БухСправка.ТабличнаяЧасть.Очистить();
    
    // Проводка по дооценке/уценке стоимости ОС (счет 01)
    Если Данные.СуммаИзмененияСтоимости > 0 Тогда
        // Если сумма положительная - это дооценка: Дебет 01 Кредит 83
        СчетДт = "01.01";
        СчетКт = "83.01";
    Иначе
        // Если сумма отрицательная - это уценка: Дебет 91.02 Кредит 01
        СчетДт = "91.02";
        СчетКт = "01.01";
    КонецЕсли;
    
    СтрокаПроводки = БухСправка.ТабличнаяЧасть.Добавить();
    ЗаполнитьЗначенияСвойств(СтрокаПроводки, 
    Новый Структура("ДебетСчет, КредитСчет, Сумма", 
    СчетДт, СчетКт, Abs(Данные.СуммаИзмененияСтоимости)));
    
    // Проводка по корректировке амортизации (счет 02)
    Если Данные.СуммаИзмененияАмортизации > 0 Тогда
        // Дооценка амортизации: Дебет 83 Кредит 02
        СчетДт = "83.01";
        СчетКт = "02.01";
    Иначе
        // Уценка амортизации: Дебет 02 Кредит 91.01
        СчетДт = "02.01";
        СчетКт = "91.01";
    КонецЕсли;
    
    СтрокаПроводки = БухСправка.ТабличнаяЧасть.Добавить();
    ЗаполнитьЗначенияСвойств(СтрокаПроводки, 
    Новый Структура("ДебетСчет, КредитСчет, Сумма", 
    СчетДт, СчетКт, Abs(Данные.СуммаИзмененияАмортизации)));
    
    // Записываем и проводим документ
    БухСправка.Записать();
    БухСправка.Провести();
    
    Сообщить("Создана бухгалтерская справка № " + БухСправка.Номер);
    
КонецПроцедуры

&НаСервере
Процедура СоздатьИзменениеПараметровАмортизации(Данные)
    
    // Создаем документ для изменения будущих параметров начисления амортизации
    ДокИзменение = Документы.ИзменениеПараметровАмортизацииОС.СоздатьДокумент();
    ДокИзменение.Дата = ДатаПереоценки;
    ДокИзменение.ОсновноеСредство = Данные.ОбъектОС;
    
    // Указываем новую стоимость для расчета будущей амортизации в БУ
    ДокИзменение.СтоимостьБУ = Данные.НоваяСтоимость;
    ДокИзменение.СтоимостьНУ = Неопределено; // В налоговом учете стоимость не меняется!
    
    // Записываем и проводим документ
    ДокИзменение.Записать();
    ДокИзменение.Провести();
    
    Сообщить("Параметры амортизации основного средства обновлены.");
    
КонецПроцедуры
```

## 🛠️ Инструкция по добавлению обработки в 1С для бухгалтера

Для добавления обработки не требуются права программиста. Следуйте этой инструкции.

### Шаг 1: Сохранение файла обработки
Программист или администратор должен предоставить вам файл обработки с расширением **`.epf`**. Сохраните его в удобную папку на вашем компьютере.

### Шаг 2: Открытие обработки в 1С
1.  Запустите программу 1С и откройте свою базу «Бухгалтерия предприятия».
2.  Перейдите в меню **«Файл»** → **«Открыть»**.
3.  В появившемся окне найдите и выберите файл обработки (с расширением `.epf`), который вы сохранили на Шаге 1.
4.  Нажмите **«Открыть»**.

### Шаг 3: Использование обработки
После открытия появится окно вашей обработки «Переоценка ОС». Для работы:
1.  **Выберите основное средство**: Нажмите на кнопку выбора в поле «Объект переоценки» и выберите из списка нужный объект ОС.
2.  **Укажите дату переоценки**: Обычно это последний день отчетного периода (например, 31 декабря).
3.  **Введите новую стоимость**: Введите справедливую рыночную стоимость объекта, определенную по результатам оценки.
4.  **Нажмите кнопку «Провести переоценку»**: Обработка автоматически выполнит все необходимые действия:
    *   Рассчитает суммы и создаст документ **«Бухгалтерская справка»** с проводками.
    *   Создаст документ **«Изменение параметров амортизации ОС»**, чтобы амортизация в будущем начислялась correctly от новой стоимости.

После выполнения вы увидите сообщение об успешном завершении. Созданные документы можно найти в соответствующих журналах.

## 🔢 Пример расчета переоценки

Рассмотрим практический пример с цифрами.

**Исходные данные на 31.12.2024:**
*   Объект ОС: «Станок токарный»
*   Первоначальная стоимость: 1 000 000 руб.
*   Сумма начисленной амортизации (БУ): 400 000 руб.
*   Остаточная стоимость: 1 000 000 - 400 000 = **600 000 руб.**
*   По данным оценщика, справедливая стоимость станка: **750 000 руб.**

**Задача**: Провести переоценку, увеличив балансовую стоимость до справедливой.

### Шаг 1. Расчет коэффициента пересчета
`Коэффициент = Справедливая стоимость / Первоначальная стоимость`
`Коэффициент = 750 000 / 1 000 000 = 0.75`

### Шаг 2. Расчет новой стоимости и новой амортизации
*   **Новая первоначальная стоимость**: `1 000 000 * 0.75 = 750 000 руб.`
*   **Новая сумма амортизации**: `400 000 * 0.75 = 300 000 руб.`
*   **Новая остаточная стоимость**: `750 000 - 300 000 = 450 000 руб.` (или проще: `600 000 * 0.75 = 450 000 руб.`)

### Шаг 3. Определение сумм для проводок
*   **Сумма дооценки стоимости**: `750 000 - 1 000 000 = -250 000 руб.` (Фактически, в нашем случае это уценка, но принцип расчета одинаков).
*   **Сумма корректировки амортизации**: `300 000 - 400 000 = -100 000 руб.`

### Шаг 4. Отражение в бухгалтерском учете
Обработка создаст в документе «Бухгалтерская справка» следующие проводки:

| Дебет | Кредит | Сумма       | Содержание операции |
| :---- | :----- | :---------- | :------------------ |
| 91.02 | 01.01  | 250 000 руб.| Уценка стоимости ОС |
| 02.01 | 91.01  | 100 000 руб.| Уценка амортизации ОС |

**Результат**: После переоценки объект будет учитываться по новой стоимости 750 000 руб., а ежемесячная амортизация будет начисляться исходя из этой новой стоимости. В налоговом учете изменения не производятся, что приводит к возникновению временных разниц и отложенного налога на прибыль (учитывается автоматически при закрытии месяца) .
