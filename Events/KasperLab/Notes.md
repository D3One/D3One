**Название:** Анализ образца Backdoor.Win32.Agent.gen  
**Источник:** Образец предоставлен «Лабораторией Касперского» в 2017 году  
**Время выполнения:** 2 часа  
**Уровень сложности:** Легкий  

---

#### **Цель задания**
Провести статический и базовый динамический анализ предоставленного бинарного файла, определить его функционал, идентифицировать ключевые секции и вызовы API Windows, а также предложить методы противодействия.

---

#### **Исходные данные**
- **Файл:** `sample_malware.exe`
- **Размер:** 112 КБ
- **SHA-256:** `a1b2c3d4e5f67890...` (указать хэш для проверки)
- **Тип:** PE32-исполняемый файл (GUI)

---

#### **Шаги выполнения**

1. **Статический анализ**
   - Используйте инструменты вроде **PE-bear**, **CFF Explorer** или **HxD** для изучения структуры PE-файла.
   - Определите секции (например, `.text`, `.data`, `.rsrc`) и их характеристики.
   - Извлеките импортируемые функции (API-вызовы) с помощью **IDA Pro** или **Ghidra**.
   - Проанализируйте строки в бинарном файле.

2. **Анализ функционала**
   - Определите назначение вредоноса (например, бэкдор, кейлоггер, шифровальщик).
   - Выявите основные функции: сетевое взаимодействие, маскировка, persistence.

3. **Динамический анализ (опционально, если есть время)**
   - Запустите файл в изолированной среде (например, **VMware + Wireshark**).
   - Мониторьте изменения в реестре, файловой системе и сетевую активность.

---

#### **Ожидаемые результаты**
1. **Описание функционала:**  
   - Пример: *«Вредонос создает копию себя в `%AppData%\system.exe`, добавляет автозагрузку через реестр (`HKLM\Software\Microsoft\Windows\CurrentVersion\Run`) и подключается к C&C-серверу через TCP-порт 443»*.

2. **Ключевые API-вызовы:**  
   - `WriteFile` – запись данных в файл.
   - `RegSetValueEx` – изменение значений в реестре.
   - `WinHttpConnect` – сетевое соединение.
   - `CreateMutex` – избежание многократного запуска.

3. **Секции PE-файла:**  
   - `.text` – основной код.
   - `.data` – данные (например, URL C&C-сервера).
   - `.rsrc` – ресурсы (иконки, строки).

4. **Предложения по противодействию:**  
   - Блокировка сетевых соединений на порт 443 для недоверенных процессов.
   - Мониторинг автозагрузки реестра.
   - Сигнатуры для антивирусов: хэш файла, строки в коде.

---

#### **Пример отчета**
```markdown
# Анализ sample_malware.exe

## Функционал
- **Тип:** Бэкдор с persistence.
- **Действия:** 
  - Копирует себя в `C:\Users\%USERNAME%\AppData\Roaming\system.exe`.
  - Добавляет запись в реестр для автозагрузки.
  - Подключается к C&C-серверу `185.243.115.230:443`.

## API-вызовы
- `kernel32.dll`: `CreateFileA`, `WriteFile`.
- `advapi32.dll`: `RegOpenKeyEx`, `RegSetValueEx`.
- `winhttp.dll`: `WinHttpOpen`, `WinHttpConnect`.

## Секции
- `.text`: Код (RVA: 0x1000, Size: 0x4000).
- `.data`: Данные (RVA: 0x6000, Size: 0x1000).
- `.rsrc`: Ресурсы (RVA: 0x8000, Size: 0x2000).

## Противодействие
- Удалить файл `system.exe` из `%AppData%`.
- Проверить реестр на наличие записи `SystemLoader`.
- Добавить правило в брандмауэр для блокировки IP 185.243.115.230.
```
