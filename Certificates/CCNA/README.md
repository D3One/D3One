
## 🔰 Introduction to the CCNA (2014 by Ivan Piskunov)

The **Cisco Certified Network Associate (CCNA)** certification during the 2010-2014 period validated a candidate's ability to install, configure, operate, and troubleshoot medium-sized routed and switched networks. The curriculum, often associated with versions 4.x and 5.x of the Cisco Networking Academy courses, covered fundamental topics like IP addressing, VLANs, routing protocols (RIP, EIGRP, OSPF), ACLs, NAT, and WAN technologies. This certification was highly valuable due to the exponential growth of network-connected devices and the critical role of robust network infrastructure in business operations.

### 📚 CCNA v5.0 Exam Practice Questions (2014 Context)

The following questions cover the core domains of the CCNA exam from your certification period.

| Question | Answer & Explanation |
| :--- | :--- |
| **1. What is the purpose of the `ip default-gateway` command when configured on a Layer 2 switch?**  | **To allow the switch to be managed remotely from a different network.** A Layer 2 switch uses the default gateway to forward IP packets to remote networks for management purposes (e.g., SSH, Telnet). It is not used for forwarding user data frames. |
| **2. A technician made multiple changes to the running configuration that did not solve a problem. The changes were not saved. What is the fastest way to discard these changes?**  | **Issue the `reload` command without saving the running configuration.** This reboots the device and loads the last saved startup configuration from NVRAM, discarding all unsaved changes in RAM. |
| **3. Why is it important to configure a hostname on a network device?**  | **To identify the device during remote access (SSH or Telnet).** The hostname is displayed in the command-line prompt, which is crucial for network administrators managing multiple devices. |
| **4. Which access method is the most secure for remote CLI management of a Cisco switch?**  | **SSH (Secure Shell).** SSH encrypts the entire session, including the user ID and password, unlike Telnet, which sends all data in plain text. |
| **5. Which interface on a Layer 2 switch allows for remote management?**  | **The Switch Virtual Interface (SVI).** This is a virtual interface, typically the interface for VLAN 1 (or a management VLAN), which is assigned an IP address for management. |
| **6. What is the effect of the `service password-encryption` command?**  | **It encrypts all plaintext passwords in the configuration file.** This prevents someone from viewing passwords like the `enable secret` or line passwords when using the `show running-config` command. |
| **7. Match the CLI hotkey: `Ctrl-R`.**  | **Redisplays the current command line.** This is useful if a system message appears and obscures the command you are typing. |
| **8. Before upgrading the IOS on a router, which three questions should be answered? (Choose three.)**  | **- What models of routers require upgrades?**<br>**- Do they have enough RAM and flash?**<br>**- What features are required?** These factors determine the correct IOS image file to use. |
| **9. What is the primary benefit of DHCP?**  | **Hosts can get an IP address without manual configuration.** DHCP automates IP address assignment, reducing administrative overhead and preventing configuration errors. |
| **10. Which two functions are provided by the context-sensitive help feature?**  | **- Displaying a list of all available commands in the current mode.**<br>**- Determining which options are available for an entered command.** Pressing '?' at any point provides context-specific help. |
| **11. After booting with a valid IOS in NVRAM, which mode does a router display?**  | **User EXEC mode.** This is the first mode entered after booting, indicated by the `>` prompt. Privileged EXEC mode (`#` prompt) is entered next using the `enable` command. |
| **12. Which two statements are characteristics of flash memory?**  | **- Flash provides nonvolatile storage.**<br>**- The contents of flash may be overwritten.** Flash memory stores the IOS image and retains it when powered off (nonvolatile). |
| **13. Which three can be protected with passwords? (Choose three.)**  | **- Privileged EXEC mode.**<br>**- VTY interface.**<br>**- Console interface.** Passwords secure access to different administrative levels and ports. |
| **14. What is a user trying to determine when issuing a `ping` command?**  | **If there is connectivity with the destination device.** The `ping` utility tests reachability and measures round-trip time. |
| **15. What command on a Windows PC shows its IP configuration?**  | **`ipconfig`.** This command displays the IP address, subnet mask, and default gateway. |
| **16. Which statement is true about the running configuration?**  | **It affects the device operation immediately when modified.** The running configuration resides in RAM. Changes take effect right away but are lost on reboot unless saved. |
| **17. What is the minimum configuration for a router interface participating in IPv6 routing?**  | **To have only a link-local IPv6 address.** A link-local address is automatically created and allows communication on the local link but not for routing. A global unicast address is typically also required for full routing. |
| **18. Which wildcard mask is most efficient to permit networks 192.168.1.0/25, 192.168.0.0/25, 192.168.0.128/25, 192.168.1.128/26, and 192.168.1.192/26 in a single ACL entry?**  | **`0.0.1.255`.** A wildcard mask is the inverse of a subnet mask. This mask effectively covers the range from 192.168.0.0 to 192.168.1.255. |
| **19. Why would an administrator flood a switch's MAC address table with fictitious addresses?**  | **To determine which ports are not correctly configured to prevent MAC address flooding.** This is a security test to find ports without port security that are vulnerable to MAC flooding attacks. |
| **20. Which two configurations are applied to a Layer 3 switch to connect to a router for Internet connectivity?**  | **- `(config)# interface gigabitethernet 1/1`<br>  `(config-if)# no switchport`<br>  `(config-if)# ip address 192.168.1.2 255.255.255.252`**<br>**- `(config)# ip routing`.** The `no switchport` command makes the port a routed port, and `ip routing` enables Layer 3 routing on the switch. |
| **21. Which two statements are true about full-duplex communications?**  | **- Full duplex offers 100% potential use of the bandwidth.**<br>**- Full duplex allows both ends to transmit and receive simultaneously.** Full-duplex communication doubles the potential use of the bandwidth compared to half-duplex. |
| **22. Where are the `lt` (less than) or `gt` (greater than) keywords used?**  | **In an IPv4 extended ACL that allows packets from a range of TCP ports.** These keywords are used to filter based on port numbers within a specified range. |
| **23. What command prepares a switch port for the router-on-a-stick method?**  | **`Switch(config-if)# switchport mode trunk`.** This configures the port to trunk and carry traffic for multiple VLANs to the router. |
| **24. A static route `ip route 209.165.200.224 255.255.255.224 S0/0/0` prevents LAN users from reaching the Internet. How should it be changed?**  | **Change the destination to `0.0.0.0 0.0.0.0` (default route).** The original route is too specific. A default route acts as a gateway for all traffic not matching other routes in the table. |
| **25. What happens when a device in VLAN 20 sends a broadcast frame?**  | **Only devices in VLAN 20 see the frame.** VLANs create separate broadcast domains. Broadcast traffic is confined to the VLAN where it originates. |
| **26. What type of traffic has a one-way delay requirement of less than 150 ms?**  | **VoIP (Voice over IP).** Low latency, jitter, and packet loss are critical for acceptable voice quality. |
| **27. What benefit does NAT64 provide?**  | **It allows IPv6 hosts to connect to an IPv4 network by translating addresses.** NAT64 is a transition mechanism that facilitates communication between IPv6-only and IPv4-only networks. |
| **28. Which two are features of a link-state routing protocol like OSPF?**  | **- Routers create a topology of the network using information from other routers.**<br>**- Routers send triggered updates in response to a change.** Link-state protocols use a topological database and send updates only when a change occurs, converging faster than distance-vector protocols. |
| **29. Which switching method drops frames that fail the FCS check?**  | **Store-and-forward switching.** This method stores the entire frame, checks the FCS for errors, and discards the frame if it's invalid. Cut-through switching forwards frames immediately after reading the destination MAC address, potentially forwarding errors. |
| **30. When a Cisco switch receives untagged frames on an 802.1Q trunk port, which VLAN are they assigned to?**  | **Native VLAN ID.** Traffic for the native VLAN is sent across a trunk port without an 802.1Q tag. |
| **31. How is the Router ID for an OSPFv3 router determined?**  | **The highest IPv4 address on an active interface.** Even in an IPv6 environment (OSPFv3), the Router ID is a 32-bit number, typically an IPv4 address. It can be manually configured. |
| **32. Which command set allows only two specific laptops to use an Ethernet port and log violations without shutting down the port?**  | **`switchport mode access`<br>`switchport port-security`<br>`switchport port-security maximum 2`<br>`switchport port-security mac-address sticky`<br>`switchport port-security violation restrict`.** The `violation restrict` option causes the switch to log the violation but not shut down the port. |
| **33. What causes a port to be put in an "err-disable" state?**  | **Port security was enabled, and an unauthorized connection was made.** This is a security feature that automatically disables a port when a violation occurs. |
| **34. Which two are characteristics of routed ports on a multilayer switch?**  | **- They are not associated with a particular VLAN.**<br>**- In a switched network, they are configured between core and distribution layers.** A routed port is a physical port that acts like a router interface, requires an IP address, and is not a member of a VLAN. |
| **35. Which IPv6 ACE is implicitly added to allow neighbor discovery?**  | **`permit icmp any any nd-na`.** This implicit rule allows Neighbor Discovery (ND) messages, which are essential for IPv6 devices to find each other on the same link. |

### 📖 Recommended Study Resources 

*   **Official Cisco Materials:** The primary study resource was the **Cisco Networking Academy** curriculum for CCNA Routing and Switching (version 5.0). These courses provided structured learning and hands-on labs .
*   **Official Certification Guide:** The definitive book for the exam was **"CCNA Routing and Switching Official Cert Guide Library"** by Wendell Odom, published by Cisco Press. This library covered all exam topics in depth.
*   **Online Practice and Communities:** Websites like **9tut.com** provided tutorials and practice questions that were widely used by candidates for review and self-testing . Community-driven sites and forums were invaluable for discussing topics and troubleshooting lab scenarios.

This guide, compiled by **Ivan Piskunov (c) 2024**, is based on the public domain exam topics and practice questions from the 2010-2014 period for the CCNA Routing and Switching certification. The current CCNA exam (200-301) has been significantly updated since then to include modern topics like network programmability, automation, and security fundamentals.
