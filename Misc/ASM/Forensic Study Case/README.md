## About This Project

This directory contains educational digital forensics cases that were used to master fundamental analysis techniques of operating systems and low-level artifacts as part of the university curriculum. The cases reflect typical compromise scenarios and investigation methods relevant to the late 2000s.

Key topics covered in the cases:
- Analysis of disk images and memory dumps
- Incident investigation on Windows and Linux OS
- Hunting for artifacts of unauthorized access
- Analysis of malicious activity
- Timeline reconstruction of events
