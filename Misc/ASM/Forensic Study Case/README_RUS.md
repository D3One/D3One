# Forensic Study Cases (2008-2010 University Curriculum)

**Автор:** Усенко Олег (Oleg Usenko), Кафдера ИБ, Факультет Информационных систем

**Учебное заведение:** САПЭУ 

---

## О проекте

Эта директория содержит учебные кейсы по цифровой криминалистике (digital forensics), которые использовались для освоения базовых навыков анализа операционных систем и низкоуровневых артефактов в рамках университетской программы. Кейсы отражают типичные для конца 2000-х годов сценарии компрометации систем и методы расследования.

Основные темы, затронутые в кейсах:
- Анализ дисковых образов и дампов памяти
- Расследование инцидентов на ОС Windows и Linux
- Поиск артефаков несанкционированного доступа
- Анализ вредоносной активности
- Восстановление временной линии событий

## Структура репозитория
